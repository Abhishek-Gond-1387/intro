## Featured Project
 
### Abacus: Verifying Claims About Python Functions
 
Abacus is a research prototype that checks precise claims about Python functions. It searches for counterexamples and relies on trusted checks to decide what the evidence supports. A passing finite test run is never reported as a proof.
 
**What it does**
 
- Evaluates candidate functions against a trusted oracle, with input contracts and a bounded subprocess runner
- Searches for counterexamples using fixed edge cases, Hypothesis property-based testing and LLM-proposed inputs
- Treats every model suggestion as untrusted: a claim is refuted only after a counterexample is confirmed by replay
- Keeps evidence reproducible through saved counterexamples, versioned run records and secret-safe logs
**Engineering**
 
- FastAPI service with API key authentication and idempotent run submission
- PostgreSQL with Alembic migrations, deployed locally with Docker Compose
- Cross-platform CI on GitHub Actions (Ubuntu and Windows, Python 3.11 and 3.14) with Dependabot updates
**Tech:** `Python` `FastAPI` `PostgreSQL` `Alembic` `Docker` `Hypothesis` `Gemini API` `GitHub Actions`
